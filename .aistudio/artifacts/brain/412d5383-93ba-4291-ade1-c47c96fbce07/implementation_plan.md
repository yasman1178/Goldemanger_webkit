# ترقية كارت البيع، جدول الجرد، طباعة الكشف، وإعدادات مصنعيات العيارات والضريبة

خطة تنفيذ شاملة لإعادة ضبط عرض المخزن باسمه الحقيقي في كارت البيع، وتطوير جدول الجرد ليتيح التبديل السلس بين العرض المجمع لكل صنف وعرض القطع الفردية متضمناً الحالة والمعادل العياري، وترقية طباعة كشف الجرد الحراري 80مم بالإجماليات التفصيلية، وإتاحة ضبط نسبة الضريبة والدمغة ومصنعيات العيارات (14 و 18 و 21 و 24) في إعدادات الفرع وتطبيقها إلزامياً في شاشة وفاتورة البيع.

---

## مراجعة المستخدم والقرارات المؤكدة

> [!IMPORTANT]
> تم تأكيد تفضيلات العمل التالية بناءً على إجابات الاستيضاح مع المستخدم:
> 1. **تنظيم جدول الجرد**: التبديل التفاعلي بين العرض المجمع لكل صنف وعرض القطع الفردية، مع إبراز اسم المخزن الفعلي وحالة القطعة (جديد / مجدد / كسر).
> 2. **تطبيق مصنعيات العيارات في البيع**: تطبيق مصنعية العيار إلزامياً من إعدادات الفرع (للعيارات 14 و 18 و 21 و 24) على فواتير البيع وشاشة الكاشير.
> 3. **طباعة كشف الجرد**: طباعة حرارية مقاس 80مم مخصصة للمخزن المصفى أو الصنف مع إجمالي القطع، الوزن الفعلي، ومعادل عيار 21.

---

## 1. نظرة عامة والهدف العام

- **كارت البيع (POS)**: استبدال رقم المعرف `مخزن #id` باسم المخزن الفعلي (مثل: "المخزن الرئيسي"، "خزنة العرض") مع شارة أنيقة وواضحة.
- **جدول الجرد (Inventory)**:
  - دعم زر تبديل تفاعلي (عرض مجمّع بالأصناف / عرض القطع التفصيلية).
  - ترتيب الأعمدة المعتمد: `الصنف`، `عدد القطع`، `المخزن`، `العيار`، `الحالة` (جديد / مجدّد / كسر)، `الوزن الفعلي`، `المعادل العياري (21K)`، `الإجراءات`.
- **طباعة كشف الجرد (80mm Thermal Receipt)**:
  - إظهار التفاصيل حسب الفلترة النشطة (مخزن محدد، صنف محدد، أو كشف الجرد العام).
  - إبراز إجمالي عدد القطع، إجمالي الوزن الفعلي، وإجمالي معادل عيار 21 بدقة محاسبية.
- **إعدادات الفرع والبيع (Branch Settings & Making Fees)**:
  - إظهار حقول إعدادات نسبة الضريبة والدمغة داخل صفحة إعدادات الفرع.
  - إضافة حقول تسعير مصنعية الجرام لكل عيار (عيار 14، عيار 18، عيار 21، عيار 24).
  - تطبيق مصنعية العيار المحددة إلزامياً في تسعير كروت البيع، وحساب إجمالي الفاتورة، والإيصالات.

---

## 2. تجربة المستخدم والتصميم البصري (Tablet-First & Apple Design)

- **كارت البيع بـ POS**:
  - عرض اسم المخزن بجوار شارة العيار والوزن بلون هادئ وأيقونة موقع `MapPin`.
  - عدم الاكتفاء بـ `product.storageId` واسترجاع اسم المخزن المطابق من قائمة المخازن الفعالة.
- **واجهة جدول الجرد**:
  - شريط تحكم أعلى الجدول يحتوي على زر تحويل العرض: `عرض مجمّع بالأصناف` و `عرض القطع التفصيلية`.
  - في العرض المجمّع: تظهر كل فئة أو صنف بسطر موحد يوضح اسم الصنف، عدد القطع المتاحة، المخزن/المخازن، العيار، الحالة، إجمالي الوزن، المعادل العياري، وزر تفاصيل.
  - في عرض القطع: يظهر كود القطعة/الباركود، اسم المنتج، المخزن، العيار، الحالة (`جديد`، `مجدّد`، `كسر`)، الوزن، معادل 21، وأزرار نقل وطباعة الباركود.
  - الأرقام المالية والأوزان والعيارات بـ `tabular-nums` لضمان المحاذاة العمودية الدقيقة.
- **برنت كشف الجرد 80مم**:
  - مخصص لطباعة ماكينات الفواتير الحرارية مع إبراز عنوان الفلترة (مثل: "كشف جرد: خزنة العرض - سلاسل وعقود").
  - جدول مقتضب ومنظم وواضح بدون هوامش مهدورة.
- **قسم مصنعيات العيارات والضريبة في إعدادات الفرع**:
  - كارت إعدادات أنيق داخل صفحة الإعدادات يتيح تحديد مصنعية الجرام لعيارات 14، 18، 21، 24.
  - شريط سريع لحفظ التعديلات مع مزامنة فورية في `tax-store` وحفظها في إعدادات النظام `keyValues`.

## 3. القرارات والبدائل الفنية

- **القرار 1: آلية التبديل بين العرض المجمع وعرض القطع**:
  - *الحل المعتمد*: توفير تحكم Segmented Switch أعلى جدول الجرد يسمح للتاجر بالتبديل الفوري بين النمط التجميعي للصنف ونمط القطع الفردية، مع الحفاظ على الفلاتر النشطة (المخزن، التصنيف، نطاق الوزن، البحث).
- **القرار 2: تطبيق مصنعية العيار إلزامياً**:
  - *الحل المعتمد*: إنشاء متجر لمصنعيات العيارات الافتراضية للفرع (`karatMakingStore` أو توسيع `tax-store`) لتخزين مصنعيات 14 و 18 و 21 و 24. عند حساب سعر البيع للبند في السلة أو الكارت، يتم تطبيق مصنعية العيار المحددة بالفرع إلزامياً ما لم تكن صفرية.
- **القرار 3: الربط بين معرف المخزن واسمه**:
  - *الحل المعتمد*: بناء خريطة بحث سريعة `Map<number, string>` للمخازن وتمريرها لكافة كروت المنتجات ومكونات الجرد لضمان عدم ظهور أرقام خام للمخازن نهائياً.

## 5. خطوات التنفيذ والتحقق

1. **كارت البيع بـ POS**:
   - تعديل `ProductGrid.tsx` لعرض اسم المخزن الفعلي في كارت المنتج وفي الـ QuickView بدلاً من `مخزن #id`.
2. **إعدادات الفرع (الضريبة ومصنعيات العيارات)**:
   - توسيع `SettingsPage.tsx` وإضافة قسم إعدادات الفروع متضمناً نسبة الضريبة والدمغة ومصنعيات العيارات 14، 18، 21، 24.
   - مزامنة القيم مع `useTaxStore` وتحديث دالة حساب سعر البيع `salePriceFor` و `cartLineMath` لتعتمد مصنعية عيار الفرع الإلزامية.
3. **جدول الجرد المتكامل**:
   - تطوير `InventoryPage.tsx` لإضافة نمط التبديل بين العرض المجمع لكل صنف وعرض القطع الفردية.
   - تطبيق ترتيب الأعمدة المطلوب وعرض اسم المخزن الفعلي وحالة المشغول (جديد / مجدد / كسر).
4. **طباعة كشف الجرد 80مم**:
   - تحديث `InventoryReceiptPrint.tsx` لطباعة تفاصيل الأصناف المصفاة والمخزن المختار مع إجمالي القطع، الوزن الفعلي، ومعادل 21.
5. **التحقق والاختبار**:
   - تشغيل `npm run typecheck` و `npm run lint` و `npm run test` و `npm run build` للتأكد من خلو المشروع من أية أخطاء.
